## Brand & Style

This design system translates the effortless hospitality of modern platform travel into the Dutch aquatic landscape. It caters to young families booking "Diploma A/B/C" swimming tracks, lane swimmers pursuing athletic routines ("Banenzwemmen"), recreational explorers seeking subtropical wave pools, and open-water swimmers checking real-time water conditions.

The visual direction merges **Airbnb-level editorial clarity** with **aquatic freshness**. The canvas relies on immaculate whites, crisp architectural hairpins (`#EBEBEB`), deep carbon typography (`#222222`), and secondary slate tones (`#717171`). Color is deployed deliberately: vibrant deep cyan anchors navigational intent and trust, while warm safety amber marks seasonal alerts and open-water temperature warnings. 

The aesthetic is clean, inviting, and tactile, utilizing rounded corners, pill-shaped utility search bars, floating map toggles, and layered booking modules.

## Colors

The palette establishes an open, hygienic, and aquatic atmosphere while maintaining strict contrast compliance.

- **Primary (`#008489`)**: Used for primary action buttons, active search states, interactive map pins, verified facility badges, and positive ratings. It anchors trust and reflects clear indoor pool water.
- **Secondary (`#0284C7`)**: Used for secondary accents, water temperature tags ("Watertemperatuur"), lane availability indicators, and interactive links.
- **Neutral (`#222222`)**: Pure charcoal for maximum readability across headlines, body typography, and prominent high-contrast icons. It replaces stark `#000000` to prevent harsh visual clipping against pure white backgrounds.
- **Canvas & Borders**: Pure white (`#FFFFFF`) serves as the base layer, framed with razor-sharp `#EBEBEB` border strokes to separate content tiers without visual weight.
- **Accent Seasonal (`#F97316`)**: Reserved for outdoor safety alerts, seasonal open-water conditions (blauwalgen waarschuwingen, wetsuit advisories), and flash booking slots for diploma testing.

## Typography

The type system uses **Plus Jakarta Sans** across all levels, capturing the approachable geometric clarity of Airbnb's Cereal while remaining open and friendly for multi-generational Dutch audiences.

- **Headlines**: Set at extra-bold (`800`) and bold (`700`) weights with tight negative letter tracking (`-0.01em` to `-0.02em`), providing presence and editorial structure to listing titles ("Zwemparadijs De Mirandabad") and section headers ("Zwemles A/B/C in Amsterdam").
- **Body Text**: Tuned for maximum scanning speed. Secondary metadata such as address lines, distance indicators, and opening hours always utilize regular (`400`) weight rendered in `#717171`.
- **Labels & Micro-copy**: Emphasized with medium-to-bold weights (`600`–`700`) and slight positive tracking for chips, status tags ("28.5°C", "Banen vrij"), and compact pricing labels ("vanaf € 6,50").

## Layout & Spacing

The layout is built upon an adaptive 12-column grid system paired with horizontal scroll zones on smaller viewports.

- **Breakpoints**:
  - `Mobile` (&lt; 768px): 4 columns, `margin-mobile` (1.25rem / 20px), gutters of 16px. Category filters switch to an edge-to-edge swipeable container. The search bar condenses into a single floating top bar.
  - `Tablet` (768px – 1120px): 8 columns, 24px gutters, dynamic horizontal margins. Listing grids display 2 across.
  - `Desktop` (&gt; 1120px): 12 columns, max-width of 1440px centered, `margin` (3rem / 48px), 24px gutters. Card grids scale from 3 to 4 items per row, or split 50/50 alongside a fixed interactive map.

- **Spacing Cadence**:
  - `space-xs` (4px) and `space-sm` (8px): Icon-to-label gaps, chip inner padding, badge offsets.
  - `space-md` (16px): Card interior padding, gap between card text elements, form field vertical padding.
  - `space-lg` (24px): Grid gaps, modal card padding, section separation on mobile.
  - `space-xl` (40px): Section divisions, sticky widget outer spacing, hero bottom margins.

## Elevation & Depth

Visual hierarchy uses crisp, ambient drop shadows and hairline surface dividers, avoiding heavy drop shadows or skeuomorphic gradients.

- **Base Layer (Surface Level 0)**: Pure white canvas `#FFFFFF` or soft utility background `#F7F7F7`. Separated by 1px borders in `#EBEBEB`.
- **Card Default (Surface Level 1)**: Flat layout bound by image aspect ratio with a delicate border (`#EBEBEB`). Transitions smoothly to **Hover State**: `box-shadow: 0 8px 24px rgba(0, 0, 0, 0.08)` and subtle `-translate-y-0.5`.
- **Floating Controls (Surface Level 2)**: Sticky map toggle buttons ("Kaart tonen"), pill search modules, and desktop sticky booking widgets use `box-shadow: 0 6px 16px rgba(0, 0, 0, 0.08), 0 1px 4px rgba(0, 0, 0, 0.04)`.
- **Modals & Overlays (Surface Level 3)**: Date/time slot pickers, filter drawouts, and full-screen booking trays use `box-shadow: 0 12px 32px rgba(0, 0, 0, 0.12)`, underpinned by a backdrop scrim of `rgba(34, 34, 34, 0.3)`.

## Shapes

The interface balances organic, friendly curves with architectural structure:

- **Pill (Full Radius / `rounded-full` / 9999px)**: Reserved for primary and secondary search bars, interactive map triggers ("Toon kaart / Toon lijst"), filter category chips, badge counters, and primary call-to-action buttons.
- **Card Standard (`rounded-2xl` / 16px)**: Applied to listing photo carousels, pool preview cards, review containers, and modal sheets.
- **Containers & Form Fields (`rounded-xl` / 12px)**: Applied to input groups (location picker, swimmer count selector), sticky reservation boxes, and notification alert cards.
- **Micro Radii (`rounded-md` / 6px)**: Checkboxes, amenity icons, and miniature rating tags.

## Components

### Buttons
- **Primary Action**: Solid `#008489` fill, white `#FFFFFF` text, `rounded-full`, height 48px, horizontal padding 24px, font `label-lg`. Active hover shifts to a deeper hue (`#006C70`). Example: *"Bekijk beschikbaarheid"*, *"Boek zwemles"*.
- **Secondary Action**: Border button with 1px `#222222` outline, pure white or transparent fill, charcoal `#222222` text, `rounded-full`.
- **Ghost Utility**: Transparent fill, `#222222` text with underline on hover, used for secondary actions like *"Wis filters"* or *"Deel locatie"*.

### Search Pill Bar (Zoekbalk)
- Segmented container with a soft outer shadow (`0 2px 8px rgba(0,0,0,0.08)`) and `#EBEBEB` border.
- Sections partitioned by vertical 1px divider lines:
  1. *Waar* ("Zoek stad, postcode of zwembad")
  2. *Type* ("Zwemles, Banen, Recreatie")
  3. *Wie* ("Aantal personen / Diploma niveau")
- Terminal end houses a circular teal button (`#008489`) containing a crisp white search magnifying glass icon.

### Cards (Zwembad Card)
- **Visuals**: Aspect ratio 20:19 or 4:3 image carousel with border radius of 16px (`rounded-2xl`). Subtle top-right floating heart icon for favorites.
- **Content Block**:
  - Row 1: Title ("Subtropisch Zwembad De Scheg") in `headline-sm` with right-aligned rating ("★ 4.86").
  - Row 2: Secondary location label ("Deventer • 32 km afstand") in `body-md`, `#717171`.
  - Row 3: Live condition tags ("Watertemperatuur 31°C • Recreatiebad").
  - Row 4: Price presentation ("**€ 8,95** per sessie") with `label-lg` styling.

### Filter Chips (Categorieën)
- Horizontal scroll rail featuring SVG category icons (e.g., Wave icon for *Subtropisch*, Goggles icon for *Banenzwemmen*, Certificate icon for *Zwemles A/B/C*, Wetsuit icon for *Buitenwater*).
- Default state: Gray `#717171` icon and label with bottom 2px transparent border.
- Active state: `#222222` icon and label with bottom 2px `#222222` indicator.

### Input Fields & Selectors
- Floating-label style enclosed in a 1px border (`#DDDDDD`).
- Focused states transition the border to `#222222` without expanding border width.
- Quantity counters ("Aantal kinderen / Volwassenen") feature circular stepper buttons (`-` / `+`) bounded by 1px `#DDDDDD` outlines.

### Badges & Alerts
- **Diploma Badge**: Soft teal pill (`#E6F4F5`) with teal text (`#008489`), label: *"Diploma A Garantie"*.
- **Seasonal Wetsuit / Natuurwater Banner**: Soft warm container (`#FFF7ED`) with `#F97316` border and accent text, displaying Rijkswaterstaat/Zwemwater.nl data: *"Advies: Wetsuit aanbevolen (Watertemperatuur 16.2°C)"*.
